## 🔶 Что такое Lucky Carrot

**Lucky Carrot** — это платформа для признания заслуг и поощрения сотрудников (Employee Recognition & Rewards). Интеграция Strata с Lucky Carrot позволяет:

| Функция                 | Описание                                                             |
| ----------------------- | -------------------------------------------------------------------- |
| **Auto-sync employees** | Автоматическая синхронизация сотрудников из Lucky Carrot в Strata    |
| **Inbound webhooks**    | Мгновенное получение изменений о сотрудниках (создание, обновление)  |
| **Deactivate missing**  | Автоматическая деактивация сотрудников, отсутствующих в Lucky Carrot |

> **Назначение:** синхронизация каталога сотрудников. Lucky Carrot является источником данных (source of truth) для списка сотрудников.

## 📋 Предварительные требования

Перед началом настройки убедитесь, что у вас есть:

1. **Активная учётная запись Lucky Carrot** — зарегистрируйтесь на [luckycarrotapp.com](https://luckycarrotapp.com)
2. **Права администратора** в Lucky Carrot — для создания API-ключей
3. **Права администратора** в Strata Platform (роль `Admin` или `Superadmin`)

## 🔑 Как получить API Key от Lucky Carrot

Для подключения необходимо сгенерировать API-ключ в панели управления Lucky Carrot.

### Шаг 1. Вход в панель управления Lucky Carrot

1. Перейдите на [luckycarrotapp.com](https://luckycarrotapp.com) и войдите в свою учётную запись
2. Откройте **Settings** → **API Keys** (или **Integrations**)

### Шаг 2. Создание API-ключа

1. Нажмите **«Create API Key»** / **«Generate New Key»**
2. Заполните:
   - **Название:** `Strata HR Sync` (или любое другое)
   - **Разрешения (Permissions):**
     - ✅ `Read employees` — чтение списка сотрудников
     - ✅ `Read departments` — чтение отделов
3. Нажмите **«Create»**

### Шаг 3. Сохранение ключа

После создания Lucky Carrot покажет:

| Credential  | Описание                                               |
| ----------- | ------------------------------------------------------ |
| **API Key** | Строка вида `lc_xxxxxxxxxxxx` — ключ для доступа к API |

> ⚠️ **API Key** показывается только один раз. Скопируйте его сразу в надёжное место.

### Шаг 4. API URL

API URL Lucky Carrot обычно имеет формат:

```
https://api.luckycarrot.com
```

или ваш кастомный домен, если используется выделенный сервер.

### Шаг 5. Webhook URL (опционально)

Если вы планируете использовать **inbound webhook** для получения изменений о сотрудниках в реальном времени, укажите в Lucky Carrot ваш webhook endpoint (см. раздел [Inbound Webhook](#-inbound-webhook-получение-изменений-в-реальном-времени)).

#### API Key

```
Пример: lc_f8a7d6e5c4b3a2f1e0d9c8b7a6f5e4d3
```

Обычно начинается с префикса `lc_`.
Скопируйте значение **API Key** из панели Lucky Carrot. В интерфейсе Strata это поле типа `password` — значение скрыто.

> 🔐 После сохранения поле покажет `••••••••` (маска). Чтобы заменить ключ — просто введите новый. Чтобы удалить — нажмите «Remove saved value» (значок корзины рядом с полем).

#### API URL

```
По умолчанию: https://api.luckycarrot.com
```

Базовый URL для API Lucky Carrot. Если вы используете выделенный сервер или кастомный домен — укажите его здесь.

#### Webhook URL

```
Пример: https://yourapp.com/webhook/lucky-carrot
```

**Старое поле (опционально).** Рекомендуется использовать **встроенный webhook endpoint** Strata (см. раздел ниже) вместо внешнего URL.

## 📡 Inbound Webhook (получение изменений в реальном времени)

Вместо ожидания синхронизации по расписанию, Lucky Carrot может **мгновенно уведомлять** Strata о изменениях сотрудников через webhook.

### Как это работает

```
Сотрудник создан/изменён в Lucky Carrot
  → Lucky Carrot отправляет POST на webhook endpoint Strata
  → Strata проверяет подпись HMAC-SHA256
  → Изменения применяются немедленно
```

### Webhook Endpoint

Встроенный endpoint Strata для приёма вебхуков:

```
<CONVEX_SITE_URL>/webhooks/lucky-carrot/<ID_ОРГАНИЗАЦИИ>
```

Например:

```
https://your-project.convex.site/webhooks/lucky-carrot/jd3f8a...92kf
```

> ⚠️ Endpoint использует `.convex.site`, а не `.convex.cloud`. Это адрес **Convex HTTP Router**, который обрабатывает внешние HTTP-запросы.

### Как получить webhook endpoint

1. В карточке Lucky Carrot в админке включите тоггл **«Accept inbound webhooks»**
2. Под полем webhook появится секция **«Webhook endpoint»** с готовым URL
3. Скопируйте этот URL

### Webhook Secret (подпись)

Для проверки, что запросы приходят действительно от Lucky Carrot, используется HMAC-SHA256 подпись.

**Создание секрета:**

1. Сохраните конфигурацию Lucky Carrot (заполните API Key, API URL, нажмите **Save**)
2. Нажмите **Generate** в секции «Signing secret»
3. Скопируйте сгенерированный секрет **сразу** — он показывается только один раз

**Настройка в Lucky Carrot:**

1. В панели Lucky Carrot откройте настройки webhook
2. Укажите:
   - **Webhook URL:** скопированный endpoint Strata
   - **Signing Secret:** сгенерированный секрет
   - **Header for signature:** `x-luckycarrot-signature`
   - **Header for timestamp:** `x-luckycarrot-timestamp`

> 🔐 Подпись вычисляется как `HMAC-SHA256(<timestamp>.<body>)` и передаётся в заголовке `x-luckycarrot-signature`.

### Формат запроса

Lucky Carrot отправляет POST-запрос с JSON-телом. Поддерживаются два формата:

1. **Список сотрудников** — полная выгрузка каталога
2. **Одиночное событие** — создание/обновление одного сотрудника

```json
// Пример: одиночное событие
{
  "employee": {
    "email": "john@company.com",
    "name": "John Doe",
    "department": "Engineering"
  },
  "event": "employee.updated"
}
```

```json
// Пример: список
{
  "data": {
    "items": [
      { "email": "alice@company.com", "name": "Alice Smith" },
      { "email": "bob@company.com", "name": "Bob Brown" }
    ]
  }
}
```

> 💡 Если ваш формат отличается от стандартного, используйте поле **«Employees list key»** в расширенных настройках.

### Ротация секрета

Если секрет был скомпрометирован или вы хотите его сменить:

1. Нажмите **Rotate** в секции «Signing secret»
2. Скопируйте новый секрет
3. Обновите его в настройках Lucky Carrot

> ⚠️ Предыдущий секрет становится недействительным **немедленно** после ротации.

## 🛠 Расширенные настройки (mapping)

Эти поля нужны только в том случае, если API Lucky Carrot использует нестандартный формат ответа.

| Поле                        | Назначение                                          | Пример                                      |
| --------------------------- | --------------------------------------------------- | ------------------------------------------- |
| **Sync schedule (cron)**    | Cron-выражение для автоматической синхронизации     | `0 3 * * *` (каждый день в 3:00)            |
| **Employees endpoint path** | Путь к эндпоинту сотрудников (относительно API URL) | `/api/v1/employees`                         |
| **Employees list key**      | JSON-ключ, содержащий массив сотрудников            | `data.items`                                |
| **Field mapping (JSON)**    | Сопоставление полей Strata с полями Lucky Carrot    | `{"email":"work_email","name":"full_name"}` |

### Sync schedule (cron)

Определяет, как часто Strata будет синхронизироваться с Lucky Carrot. По умолчанию — **ежедневно в 3:00**.

| Интервал                  | Cron-выражение |
| ------------------------- | -------------- |
| Каждый час                | `0 * * * *`    |
| Каждые 6 часов            | `0 */6 * * *`  |
| Ежедневно в 3:00          | `0 3 * * *`    |
| Каждый понедельник в 5:00 | `0 5 * * 1`    |

> ❌ **Не ставьте чаще раза в час**, чтобы избежать превышения лимитов API Lucky Carrot.

### Employees list key

Если API Lucky Carrot возвращает сотрудников не на верхнем уровне, а внутри вложенного объекта, укажите путь через точку:

| Ответ API                                    | Значение `employeesListKey` |
| -------------------------------------------- | --------------------------- |
| `[{"email":"..."}]`                          | (оставьте пустым)           |
| `{"data":{"items":[{"email":"..."}]}}`       | `data.items`                |
| `{"result":{"employees":[{"email":"..."}]}}` | `result.employees`          |

### Field mapping (JSON)

Если названия полей в Lucky Carrot отличаются от стандартных, укажите соответствие:

```json
{
  "email": "work_email",
  "name": "full_name",
  "department": "dep_name"
}
```

| Strata поле  | Описание                       |
| ------------ | ------------------------------ |
| `email`      | Email сотрудника (обязательно) |
| `name`       | Полное имя сотрудника          |
| `department` | Название отдела                |
| `position`   | Должность                      |
| `phone`      | Номер телефона                 |

> **Совет:** Оставьте поля mapping пустыми при первой настройке — Strata попытается автоопределить формат ответа. Заполните их, если синхронизация сообщает, что не нашла сотрудников.

## 🔄 Синхронизация сотрудников

### Ручная синхронизация

1. Откройте карточку Lucky Carrot в админке
2. Нажмите **Sync Now**
3. Дождитесь завершения (индикатор загрузки)
4. Статус «Sync complete» означает успех

### Автоматическая синхронизация

Если включён тоггл **Auto-sync employees**, синхронизация будет запускаться автоматически по расписанию (см. `syncSchedule`).

### Что происходит при синхронизации

1. Strata запрашивает список сотрудников из API Lucky Carrot
2. Для каждого сотрудника:
   - **Новый email** → создаётся новый пользователь в Strata
   - **Существующий email** → обновляются данные пользователя
3. Если включён тоггл **Deactivate missing**:
   - Сотрудники, которые есть в Strata, но отсутствуют в ответе Lucky Carrot, деактивируются

## ✅ Проверка работоспособности

### 1. После настройки

Откройте карточку Lucky Carrot в разделе интеграций:

- ✅ Статус **«Connected»** (зелёный индикатор)
- ✅ Кнопка **Sync Now** активна
- ✅ API Key отображается как `••••••••` (сохранён)

### 2. Проверка синхронизации

1. Нажмите **Sync Now**
2. После завершения нажмите **History** — откроется журнал синхронизаций
3. В журнале должны быть записи с количеством созданных/обновлённых сотрудников

### 3. Проверка webhook (если настроен)

1. Включите тоггл **«Accept inbound webhooks»**
2. Сгенерируйте секрет (кнопка **Generate**)
3. Зарегистрируйте endpoint в Lucky Carrot
4. Создайте нового сотрудника в Lucky Carrot
5. В течение нескольких секунд он должен появиться в Strata

## ❗ Устранение неполадок

### Ошибка «Invalid API key»

**Причина:** Неверный или отозванный API-ключ.

**Решение:**

1. Проверьте API Key в админке Strata
2. Сгенерируйте новый ключ в панели Lucky Carrot
3. Обновите ключ в Strata и нажмите **Save**

### Ошибка «API URL required»

**Причина:** Не указан базовый URL API Lucky Carrot.

**Решение:** Заполните поле **API URL** значением `https://api.luckycarrot.com` (или вашим кастомным URL).

### Ошибка синхронизации «Could not find employees»

**Причина:** Strata не смогла распознать структуру ответа от Lucky Carrot.

**Решение:**

1. Проверьте поле **Employees list key** — возможно, сотрудники находятся внутри вложенного объекта
2. Проверьте **Field mapping** — возможно, названия полей отличаются
3. Нажмите **View documentation** для получения актуальной информации о формате ответа API

### Webhook не приходит

**Причина:** Неправильная настройка webhook в Lucky Carrot.

**Решение:**

1. Убедитесь, что тоггл **«Accept inbound webhooks»** включён
2. Проверьте, что **Signing secret** сгенерирован и скопирован в Lucky Carrot
3. Проверьте, что webhook endpoint URL указан **полностью** (с `.convex.site`)
4. Проверьте заголовки в Lucky Carrot:
   - Signature header: `x-luckycarrot-signature`
   - Timestamp header: `x-luckycarrot-timestamp`

### Ошибка «413 Payload too large»

**Причина:** Lucky Carrot отправил слишком большой запрос (> 1MB).

**Решение:** Уменьшите размер пакета в настройках Lucky Carrot или отправляйте сотрудников по частям.

### Ошибка «401 Unauthorized» для webhook

**Причина:** Неверная подпись HMAC-SHA256.

**Решение:**

1. Сгенерируйте новый секрет (кнопка **Rotate**)
2. Скопируйте его в настройки Lucky Carrot
3. Проверьте, что заголовок называется `x-luckycarrot-signature`

### Синхронизация находит 0 сотрудников

**Причина:** Неправильный employees endpoint path или list key.

**Решение:**

1. Проверьте **Employees endpoint path** — укажите путь к эндпоинту списка сотрудников
2. Проверьте **Employees list key** — укажите ключ, содержащий массив сотрудников

## 🔒 Безопасность

| Мера                      | Описание                                                                                |
| ------------------------- | --------------------------------------------------------------------------------------- |
| **API Key**               | Хранится только на сервере (Convex). В ответах API маскируется как `••••••••`.          |
| **Webhook HMAC**          | Все входящие вебхуки проверяются через HMAC-SHA256 подпись для предотвращения подделки. |
| **Replay protection**     | Вебхуки с timestamp старше 5 минут отклоняются.                                         |
| **Payload limit**         | Максимальный размер тела вебхука — 1 MB.                                                |
| **Timing-safe сравнение** | Подпись проверяется через timing-safe сравнение, чтобы избежать атак по времени.        |
| **Аудит**                 | Все действия логируются в audit log и журнал синхронизаций.                             |
