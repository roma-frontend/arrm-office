# LiveKit — План интеграции видеоконференций (Teams/Zoom-подобные встречи, вебинары)

> **Статус:** план для ознакомления и последующей реализации.
> **Стек:** Next.js 15 (App Router) + Convex + react-i18next (en/ru/de/hy) + Tailwind v4.
> **Цель:** встроенные видеоконференции прямо в HR-платформе: онлайн-встречи и вебинары уровня Teams/Zoom, с интеграцией в календарь и meeting rooms.

---

## 1. Почему LiveKit (а не Zoom SDK, Agora, 100ms, Daily)

| Критерий                                    | LiveKit                        | Zoom SDK        | Agora  | Daily          |
| ------------------------------------------- | ------------------------------ | --------------- | ------ | -------------- |
| Self-hosted / свой сервер                   | ✅ Open Source (AGPL)          | ❌ нет          | ❌ нет | ❌ нет         |
| Cloud-хостинг с бесплатным тиром            | ✅ 5 000 мин/мес               | платно          | платно | 10 000 мин/мес |
| WebRTC (без плагинов в браузере)            | ✅ нативно                     | частично (WASM) | ✅     | ✅             |
| Open Source UI-киты (React)                 | ✅ `@livekit/components-react` | ❌              | ❌     | частично       |
| Запись сессий, транскрипция, E2E-шифрование | ✅ встроено                    | платные модули  | платно | платно         |
| Контроль над данными (GDPR, свой регион)    | ✅ (self-host)                 | ❌              | ❌     | ❌             |
| LiveKit Agents (AI-ассистент в комнате)     | ✅                             | ❌              | ❌     | ❌             |

**Вывод:** LiveKit — единственное решение, которое одновременно даёт (а) готовый облачный сервис для быстрого старта, (б) бесплатный self-host для экономии и контроля данных, (в) официальные React-компоненты, которые встраиваются в наш дизайн-системный UI за дни, а не недели.

**Ключевое решение:** LiveKit не хранит нашу бизнес-логику. Приложение создаёт комнату в LiveKit только когда организатор сохраняет событие, а участники получают доступ через короткоживущие JWT-токены, которые генерирует **наш** сервер (Convex action). Всё остальное (кто, когда, с какими правами) — в нашей БД.

## 3. Полный список функций (уровень Teams / Zoom)

### 3.1. Ядро видеоконференции

- [ ] **Виртуальная комната** — постоянная ссылка вида `https://app.ru/meetings/{id}` (устойчива к пересозданию события).
- [ ] **Pre-join экран** — проверка микрофона/камеры, выбор устройства, настройка имени, превью себя, «Войти без видео».
- [ ] **Сетка участников** — авто-раскладка (speaker view + grid), до 50 участников на комнату без потери качества.
- [ ] **Аудио/видео** — WebRTC (Opus + VP9/AV1/H.264), автоматическая адаптация под сеть, шумоподавление.
- [ ] **Демонстрация экрана** — весь экран / окно / вкладка, в т.ч. со звуком системного аудио.
- [ ] **Встроенный чат** — общий чат комнаты + приватные сообщения участникам.
- [ ] **Реакции** — эмодзи поверх видео (👍 ❤️ 🎉), «поднять руку».
- [ ] **Управление участниками** — mute/unmute, отключение видео, выгон, «передать роль».
- [ ] **PIN-код / ссылка-приглашение** — короткая ссылка `go.app.ru/abc123` + опциональный PIN для входа (как у Zoom).

### 3.2. Организатор (хост)

- [ ] **Панель управления** — назначать докладчика, менять раскладку, делать участников модераторами.
- [ ] **Вебинар-режим** — «только докладчик»: участники видят/слышат хоста, говорят через «поднять руку» → хост даёт слово.
- [ ] **Ожидание (lobby/waiting room)** — хост подтверждает каждого входящего до начала.
- [ ] **Запись** — облачная запись (Egress) в S3/Cloudinary, ссылка прикрепляется к событию календаря после окончания.
- [ ] **Транскрипция** (опционально, LiveKit Agents) — субтитры в реальном времени + стенограмма после встречи.

### 3.3. Интеграция с календарём (главное требование)

- [ ] **В модалке создания события** (CreateEventModal, шаг «Дополнительно») — включить переключатель **«Видеоконференция»** (сейчас там заглушка «Teams Meeting — coming soon»).
- [ ] **Автогенерация ссылки** — при сохранении события создаётся комната LiveKit, ссылка подставляется в событие.
- [ ] **Отображение** — в карточке события/детали: кнопка **«Присоединиться»** + ссылка для копирования.
- [ ] **Напоминания** — при срабатывании напоминания (уже есть reminder в событии) — уведомление с кнопкой «Присоединиться».
- [ ] **ICS/.ics экспорт** — ссылка на видео попадает в приглашение календаря (Google/Outlook).

### 3.4. Интеграция с Meeting Rooms

- [ ] **Виртуальные комнаты** — в существующем модуле комнат появляется тип «Виртуальная» (наравне с физическими): своя вместимость (лимит участников), цвет, иконка.
- [ ] **Физическая комната + видео одновременно** — событие может бронировать физическую комнату **и** иметь видеоссылку (гибридное собрание).
- [ ] **Вместимость** — лимит LiveKit-комнаты проверяется по `capacity` комнаты (уже есть в schema `meetingRooms`).

### 3.5. Дополнительно (фаза 2)

- [ ] **Breakout rooms** — разделение на группы (LiveKit поддерживает нативно).
- [ ] **AI-ассистент** (LiveKit Agents) — авто-саммари встречи, напоминание в чат после.
- [ ] **Гости без аккаунта** — вход по ссылке с именем (не требует логина в системе).
- [ ] **Пуш-уведомления** о начале встречи подключённым участникам.

### 4.1. Convex — schema (`convex/schema/`)

```ts

videoProvider: v.optional(v.literal('livekit')),
videoRecordingUrl: v.optional(v.string()), // ссылка на запись (Egress)

// meetingRooms.ts (новые поля)
isVirtual: v.optional(v.boolean()),    // true = виртуальная комната
livekitRoomName: v.optional(v.string()),

// НОВАЯ таблица meetings (метаданные встреч)
meetings: defineTable({
  eventId: v.optional(v.id('calendarEvents')),
  organizationId: v.id('organizations'),
  roomName: v.string(),          // уникальное имя комнаты LiveKit
  hostUserId: v.id('users'),
  mode: v.union(v.literal('meeting'), v.literal('webinar')),
  status: v.union(v.literal('scheduled'), v.literal('live'), v.literal('ended')),
  pinCode: v.optional(v.string()),
  createdAt: v.number(),
}).index('by_org', ['organizationId']).index('by_event', ['eventId']),
```

## 5. Тарифы и стоимость (для ознакомления)

### 5.1. LiveKit Cloud (управляемый сервис) — актуально на 2026

| Тариф          | Цена         | Включено               | Сверх лимита    | Когда подходит нам                          |
| -------------- | ------------ | ---------------------- | --------------- | ------------------------------------------- |
| **Build**      | **$0/мес**   | 5 000 WebRTC-минут/мес | —               | Разработка, тесты, демо                     |
| **Ship**       | **$50/мес**  | 150 000 мин/мес        | **$0.0005/мин** | Пилот: 20–50 сотрудников, ~2–3 встречи/день |
| **Scale**      | **$500/мес** | 1.5 млн мин/мес        | **$0.0004/мин** | Активная компания, вебинары, записи         |
| **Enterprise** | по договору  | индивидуально          | индивидуально   | Self-host миграция, SLA, свой регион        |

**Что ещё тарифицируется отдельно (по факту использования):**

- **Запись (Egress)** — от ~$0.0015/мин записанного видео (зависит от разрешения; metered от первой секунды).
- **Транскрипция/Agents** — по минутам работы агента + токены ИИ.
- **Хранение записей** — в нашем S3/Cloudinary (у нас уже есть Cloudinary в проекте — переиспользуем).

### 5.2. Self-hosted (свой сервер) — бесплатная лицензия, платишь за железо

| Вариант                                   | Ориентировочная стоимость/мес | Кому подходит                             |
| ----------------------------------------- | ----------------------------- | ----------------------------------------- |
| 1 VPS (4 vCPU / 8 GB, европейский регион) | ~$25–40/мес                   | До ~50 одновременных участников           |
| 2–3 узла + K8s                            | ~$100–300/мес                 | 100–500 одновременных, отказоустойчивость |
| Запись Egress (доп. воркер)               | +1 узел                       | Если нужна запись                         |

### 5.3. Рекомендуемая стратегия для нас

1. **Этап разработки:** LiveKit Cloud, тариф **Build ($0)** — 5 000 минут хватит на всё тестирование.
2. **Запуск в продакшн:** тариф **Ship ($50/мес)** — предсказуемо для команды до 50–100 человек. Примерный расчёт: 40 сотрудников × 2 встречи/день × 30 мин × 22 раб. дня ≈ 53 000 мин → укладываемся в 150 000.
3. **Рост:** при превышении ~150 000 мин/мес сравниваем Scale ($500) vs self-host на наших серверах (мы уже платим за инфраструктуру — self-host может выйти дешевле, плюс полный контроль данных по GDPR).

> ⚠️ **Важно:** тарифы — ориентировочные и могут меняться. Перед покупкой свериться на [livekit.com/pricing](https://livekit.com/pricing). Ключевой параметр для нас — **минуты участников** (participant-minutes): 1 встреча на 10 человек 60 минут = 600 минут.

## 6. Безопасность

- [ ] **JWT-токены с TTL** (2–6 ч) — выдаются только нашим API после проверки прав; отозвать можно инвалидацией на сервере.
- [ ] **E2E-шифрование** (LiveKit E2EE, optional) для конфиденциальных встреч (HR-переговоры).
- [ ] **PIN-код + lobby** — защита от «залётных» по ссылке.
- [ ] **Webhook-подпись** — проверка подлинности входящих событий LiveKit (X-LiveKit-Signature).
- [ ] **Права по ролям** — только организатор меняет настройки; вебинар-режим: зрители без микрофона.
- [ ] **Запись только с согласия** — баннер «идёт запись» всем участникам (требование GDPR).
- [ ] **GDPR/регион** — для EU-данных выбираем регион дата-центра LiveKit Cloud (EU) или self-host.

## 7. План реализации (фазы)

### Фаза 0 — Подготовка (1–2 дня)

- [ ] Создать аккаунт LiveKit Cloud, получить `LIVEKIT_URL` + `LIVEKIT_API_KEY` + `LIVEKIT_API_SECRET`.

- [ ] Создать в Convex таблицу `meetings` + поля в `calendarEvents`/`meetingRooms` (миграция через widen-migrate-narrow).

- [ ] Convex actions: `createRoom`, `getJoinToken`.
- [ ] Страница `/meetings/[id]`: pre-join экран + базовая комната (сетка, микрофон/камера, выход).

- [ ] Переводы en/ru/de/hy.

### Фаза 2 — Уровень Teams/Zoom (4–7 дней)

- [ ] Чат комнаты, реакции, «поднять руку», управление участниками (mute/выгнать).
- [ ] Демонстрация экрана.
- [ ] Вебинар-режим (роли host/presenter/viewer) + waiting room.
- [ ] Виртуальные комнаты в модуле meetingRooms (своя вместимость, гибридные собрания).

### Фаза 3 — Запись и прозрачность (3–5 дней)

- [ ] (Опц.) LiveKit Agents: транскрипция + авто-саммари.

### Фаза 4 — Масштабирование и полировка (по необходимости)

- [ ] Мониторинг: дашборд LiveKit, алерты на лимиты минут.
- [ ] Оценка self-host при росте (п. 5.2).

## 8. Риски и решения

| Риск                               | Решение                                                                           |
| ---------------------------------- | --------------------------------------------------------------------------------- |
| Перерасход минут (сюрприз в счёте) | Алерт при 70/90% лимита, лимиты на комнату (макс. длительность, макс. участников) |
| Плохая сеть у сотрудника           | Авто-адаптация LiveKit (Simulcast), fallback на аудио                             |
| Уязвимость через публичную ссылку  | PIN + lobby + короткоживущие токены                                               |
| Уход с LiveKit Cloud               | Self-host — тот же SDK, меняется только `LIVEKIT_URL`; код не переписывается      |
| Запись — приватность               | Согласие в UI, E2EE для HR-встреч, хранение в нашем Cloudinary                    |

## 9. Итог

LiveKit даёт нам полноценные видеоконференции уровня Teams/Zoom **внутри платформы**, без переключения на сторонние сервисы:

- 📅 **Календарь:** событие → одно нажатие → готовая видеоссылка (заглушка «coming soon» в CreateEventModal уже ждёт).

- 💰 **Стоимость:** старт $0 (Build), продакшн $50/мес (Ship) для команды до ~100 человек, рост — Scale или self-host.
- 🔒 **Безопасность:** токены с TTL, роли, PIN, GDPR-регион, E2EE для конфиденциальных встреч.
